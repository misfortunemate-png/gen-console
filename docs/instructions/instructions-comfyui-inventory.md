D:\AI\imagegen 配下には、gen-console v1.0成立以前の構築試行（CUDA互換対応・旧ワークフロー等）の残置物が混在している可能性がある。現状を一覧化し、発注者が削除可否を判断できる材料を作る。

## 調査項目

1. **custom_nodes**: 各ノードの名称・導入元・容量。gen-consoleのworkflows（anima-base.json / anima-lora.json）が参照しているか
2. **models配下**: checkpoints / loras / vae / embeddings等の各ファイル名・容量。gen-consoleでの使用有無
3. **設定ファイル**: extra_model_paths.yaml、起動引数・batファイル類、venvの数と場所（重複venvの有無）
4. **output / temp / input**: ファイル件数と合計容量のみ（**内容は読まない**）
5. **ComfyUI本体以外**: D:\AI\imagegen 直下のその他のフォルダ・ファイル（過去の構築試行の残骸があれば列挙）
6. **バージョン**: ComfyUI本体のコミット/バージョン、PyTorch・CUDAの版

## 所見の様式

各項目に以下を付す:
- 判定: 「gen-console稼働に必要」「不要（削除候補）」「不明（発注者判断）」
- 削除した場合の影響（分かる範囲で）
- 削除候補の合計容量

## 禁止事項

- 生成画像・プロンプト等の**内容**の読み取り（ファイル名・件数・容量のみ扱う）
- ComfyUIプロセスの停止・再起動（事前許可なしのセッション外プロセス操作禁止）
